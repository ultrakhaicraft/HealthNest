# HealthNest

## Introduction
HealthNest is a school medical management system, which allow medical staff to manage list of student emergency and medical equipment. The system also let parent to send the medical prescription to the medical staff, in order for staff take care of their student.
This is a personal project suggested by one of my friend.

## Function

- Role-based Authorization for Staff and Parent
- Manage list of student emergency
- Manage medical equipment
- Parent can send medical medical prescription to staff
- Manage Student Medical Prescription sent by Parent

## Technology
- .NET API for Backend
- ReactJS for Frontend
- MySQL for Database
